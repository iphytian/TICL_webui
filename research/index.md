# {% include icon.html icon="fa-solid fa-microscope" %}研究方向

实验室围绕"看得准、跟得稳、看得清"三大核心目标，在以下方向形成了系统的研究体系：

{% include section.html %}

## 研究领域

{% capture content %}

**🎯 高精度伺服控制**  
研究望远镜转台高精度伺服控制技术，包括电机驱动、速度环/位置环控制、前馈补偿与自抗扰控制，实现亚角秒级跟踪精度。

**🧠 智能控制算法**  
将强化学习、模糊控制、神经网络等人工智能方法引入望远镜控制，实现系统参数自适应调节与未知扰动抑制。

**🌌 天文图像与自动导星**  
研究星图识别、目标检测与跟踪、自动导星技术，提升望远镜成像质量与长时间曝光观测能力。

**📡 观测自动化与调度**  
面向多望远镜协同观测场景，研究任务自动规划、智能调度与故障自诊断技术，提高观测效率与可靠性。

**🔧 系统建模与仿真**  
建立望远镜机电系统高保真模型，开展控制策略的离线仿真与半实物验证，缩短算法到工程落地的周期。

**🛰️ 空间目标光电跟踪**  
面向空间目标监视与激光通信等应用，研究快速目标捕获、高动态跟踪与激光链路指向控制技术。
